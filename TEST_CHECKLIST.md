# Test checklist

Use a copy of the data you do not mind losing. Tick each line. Write down anything that looks wrong
(a screenshot helps) and send it back.

## 1. First start
- [ ] The puzzle setup appears. Draw 4+ stars, confirm, write down the recovery code.
- [ ] Closing and reopening the app asks for the puzzle again.
- [ ] A wrong puzzle shows "Not quite". "Forgot the puzzle?" accepts the recovery code.

## 2. Settings
- [ ] Save a company name. The dashboard heading changes.
- [ ] Upload a logo and a signature (PNG or JPG). Check them later on a printed report.
- [ ] Set the work schedule (start, end, break, grace).
- [ ] Switch themes. The color code (green/amber/red/blue/gray) stays the same.
- [ ] Back up now, save the file. Dashboard shows a green "Backed up" chip.

## 3. Employees and rates
- [ ] Add 3 employees with different pay types (Daily, Monthly, Weekly). IDs are EMP-0001, 0002, 0003.
- [ ] Adding the same name again shows a warning.
- [ ] Open an employee, "Rate, promotion & reviews": add a promotion dated today. It shows "Current".
- [ ] Add a raise dated next month. It shows "Scheduled".
- [ ] Add a performance review.

## 4. Attendance
- [ ] "Time in now", then "Time out now" for one employee.
- [ ] Edit another employee manually with a late time in (shows "Late") and an early time out (shows "Undertime").
- [ ] A past day with no record shows "Absent" in red.

## 5. Payroll rules and payroll
- [ ] Payroll rules: set overtime %, working days, and a deduction percent (for example SSS).
- [ ] Holidays & Leave: add a holiday and one paid leave day.
- [ ] Loans: add a small loan with an amount per payroll.
- [ ] Payroll: create a period covering your test days, press Compute payroll.
- [ ] Open an employee. Compare basic pay, absences, late, overtime and deductions with a hand calculation.
- [ ] Add an allowance and a deduction by hand. Net pay updates.
- [ ] Approve. The loan balance goes down. Reopen. The balance goes back up.
- [ ] Mark as paid (approve first).

## 6. Reports and printing
- [ ] Payslips: preview, change paper size, Save PDF, Print.
- [ ] Payroll register, deductions report, attendance report, masterlist, 13th month, loans, audit trail.
- [ ] The peso sign prints correctly. The logo and signature appear.

## 7. Dashboard and layout
- [ ] Charts show attendance and payroll. Customize hides a widget. Print dashboard matches.
- [ ] Make the window narrow (under 900 px) or open on the phone: bottom bar and "More" work.

## 8. Backup and restore
- [ ] Back up, add an employee, restore the backup. The new employee is gone.
- [ ] Audit Trail lists the changes you made.
